# Кванториум · Город идей

Одиночная браузерная игра на обычных HTML, CSS и JavaScript. Без сервера игры, аккаунтов, покупок и рекламы. Полный игровой цикл: строительство 10 направлений, преподаватели, занятия, сопровождение, тематические задания, улучшения, команды, выставки, совместный проект, 6 глав и свободная игра после финала.

## Быстрый запуск

Распакуйте архив и дважды щёлкните `index.html`. Игра запускается непосредственно в современном браузере; устанавливать Node.js, Python или Godot не нужно. Не переносите index.html отдельно от game.js, style.css и папки assets.

Вариант `Quantorium.html` уже содержит весь код и графику внутри одного файла: его можно просто открыть без распаковки и без интернета.

Для публикации поместите файлы из dist на статический хостинг. При работе со ссылкой сохранение обычно надёжнее: браузеры могут по-разному хранить localStorage для локальных файлов. Экспортируйте копию перед переносом.

## Редактирование

`game.js` — весь исполняемый код игры одним читаемым файлом. Его можно редактировать прямо в текстовом редакторе без сборки.

Для удобной разработки тот же код разделён на `engine.js`, `tasks.js` и `app.js`. После изменений этих модулей соберите новый game.js командой `node scripts/build-offline.mjs`. Node.js нужен только для этой дополнительной команды разработчика, а не для запуска игры. Не редактируйте одновременно собранный game.js и модули: следующая сборка заменит game.js содержимым модулей.

## Устройство

- index.html — входная страница, метаданные и диалог.
- style.css — адаптивная сетка, интерфейс, визуальные эффекты.
- app.js — интерфейс, три механики мини-игр, сопровождение, звук, сохранения.
- engine.js — модель, экономика, валидация, игровое время, действия.
- tasks.js — тематические последовательности и пары для 10 направлений.
- game.js — автономная сборка всех трёх модулей для запуска двойным щелчком.
- assets/rooms-a.png, rooms-b.png, rooms-c.png — 12 разных интерьеров: 10 квантумов, ресепшен и кабинет директора. В каждом атласе четыре комнаты.
- assets/characters.png — четыре персонажа по четыре кадра ходьбы. Координаты кадров заданы в sprite() и CSS; видео не используются.

У игры три общие механики (последовательности, пары, программирование маршрута), тематически адаптированные для каждого направления. Это 30 записей коллекции, не 30 независимых игровых движков. Для маршрутов предусмотрены два расположения препятствий. Сопровождение — отдельная игра: игрок и ученик идут к лестнице, поднимаются между этажами и заходят в нужную комнату. Можно удерживать экранные кнопки или стрелки клавиатуры. Выход со сцены оставляет ученика на ресепшне.

## Баланс

Начало: 280 монет, готовый IT-квантум, кандидат с навыком 5 за 120 монет. Ученики появляются каждые 12 игровых секунд. Вместимость 4/6/8. Профильный навык и количество преподавателей ускоряют занятия. Занятия и доход идут только при наличии работающего преподавателя.

Проект: 110 + 30 × (уровень − 1) монет и 35 + 10 × уровень знаний. Каждые три проекта — новый участник команды, до пяти. Выставки имеют заранее известные требования и гарантированный результат при достаточной подготовке, без случайного проигрыша. Специализация после второго уровня: −25% времени или +45 монет за проект.

Монеты тратятся на строительство и найм. Знания — на обучение, оборудование и совместный проект. Глава даёт дополнительную награду. Совместный проект «Умная теплица» объединяет IT, Био и Хайтек. Финал требует всех десяти направлений, 40 проектов и третьего уровня лаборатории, с промежуточными целями кампании.

## Сохранения

Ключ localStorage: quantorium-save-v1. Сохраняется после действий и каждые 5 секунд. Доступны экспорт и импорт JSON с проверкой структуры, версия формата 1. Импорт запрашивает подтверждение замены. Повреждённое сохранение не перезаписывается автоматически. Изменение в другой вкладке останавливает текущую вкладку, чтобы она не затёрла новый прогресс.

Прогресс локален для браузера и адреса сайта. Он не переносится автоматически между устройствами, профилями и адресами. Для переноса используйте экспорт/импорт. Очистка данных браузера удалит сохранение. Офлайн учитывается до двух часов обычного времени, а мини-игры и награды проектов требуют действий игрока. Если игра поставлена на паузу, офлайн-прогресс тоже остановлен.

## Доступность

Адаптивный интерфейс, диалоги с клавиатурным фокусом, Escape для закрытия, стрелки для программирования маршрута, выключатель звука, отключение анимаций и поддержка prefers-reduced-motion. У заданий нет лимита времени или потери валюты за ошибки. При закрытии незавершённой мини-игры группа остаётся готовой, а само задание начнётся сначала.

## Границы версии 1.0

Это завершённая одиночная кампания с конечной целью, а не коммерческий релиз, прошедший длительный плейтест. Нет облачной синхронизации, мультиплеера, индивидуального редактора этажей, монетизации и собственного серверного хранилища. Долгосрочный баланс и работа на реальных телефонах требуют пользовательского тестирования. Встроенные интерфейсы WebMCP являются необязательными и доступны только в поддерживающем браузере.

Шрифт Manrope загружается через Google Fonts; без сети используется системный шрифт. Остальные рабочие ресурсы локальны.
